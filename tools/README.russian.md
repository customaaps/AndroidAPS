Проверка русского перевода запускается без Android SDK и Gradle:

```sh
python3 tools/check_russian_resources.py
python3 tools/check_russian_resources.py --english --json > /tmp/russian-resources.json
```

Скрипт проверяет все исходные Android-каталоги `res/values` и квалификаторы без языка (`values-night`, `values-vNN` и другие), исключая результаты сборки и сохранённые исходники Boost. Он сопоставляет строки, множественные формы и массивы с `values-ru-rRU`, проверяет типы ресурсов, пустые переводы, длины массивов, индексы и типы форматных аргументов. Дополнительные русские формы `few`/`many` сравниваются с исходной формой `other`. Литералы с латиницей в пользовательских атрибутах XML-разметки выводятся для проверки.

Отсутствие отдельного русского объявления допустимо для массивов ссылок на переведённые строки, чисел и других значений без языка. `translatable="false"` не входит в покрытие. Шесть массивов настроек часов содержат сохраняемые идентификаторы; переводятся их подписи, а значения остаются прежними.

Одинаковая латиница в исходнике и переводе требует точного исключения в `russian_resource_exceptions.json`. Каждая запись содержит путь ресурса, точный исходный текст и основание. Исключения охватывают аббревиатуры, сокращения единиц, имена продуктов/протоколов, технические форматы и сохраняемые идентификаторы. Изменение текста требует повторной проверки; широких исключений по префиксам ключей нет. Статический образец `1 min` в предпросмотре виджета сохранён как число с сокращённой единицей.

Нулевой код завершения означает отсутствие перечисленных ошибок. Аудит ресурсов не заменяет сборку AAPT и просмотр экранов: динамические сообщения устройств/серверов, пользовательские названия и технические журналы могут содержать произвольный текст. Канонические трассы алгоритма Boost и оригиналы для проверки паритета не переводятся. Текст интерфейса разрешается через ресурсы текущего языка.
